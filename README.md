## Use

Open a folder and choose an image that fits your display. Search filenames for a subject, device, or resolution when available; dimensions and naming conventions vary across the archive.

To download the full collection from GitHub:

```bash
git clone --depth 1 https://github.com/MilesCorporate/The-Wallpaper-Collection.git
```

A shallow clone omits most Git history, but still downloads the collection's files. Plan for about 10.2 GiB of image and video files, in addition to Git metadata.

### 使用与格式

进入对应目录选择适合屏幕的图片。可以按主题、设备或文件名中标注的分辨率搜索；不同目录的命名方式和图像尺寸不完全相同。

HEIC/HEIF 的兼容性取决于系统及已安装的编解码器；`.mov` 文件需要兼容的视频播放器。JPEG、PNG 和 WebP 可由许多常见图片查看器打开。

克隆完整仓库：

```bash
git clone --depth 1 https://github.com/MilesCorporate/The-Wallpaper-Collection.git
```

浅克隆会省去大部分 Git 历史，但仍会下载收藏文件；图片与视频约占 10.2 GiB，此外还需要 Git 元数据空间。
