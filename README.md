## English

### Your screen deserves better than a search result

Most wallpaper repos are a dump of random downloads — mislabeled files, duplicate resolutions, no story. **The Wallpaper Collection** is the opposite: a **personal museum** built since **2018**, organized by **year** and **theme**, weighted toward **professional photography**, **brand-official art**, **gaming aesthetics**, and **mission-grade NASA imagery**.

Clone it once. Browse by mood, device, or era. Stop hunting the same Unsplash tab every Monday.

**If this repo saves you even one afternoon of searching — [leave a star](https://github.com/MilesCorporate/The-Wallpaper-Collection/stargazers).** It costs nothing. It helps this project reach the next person who needs it.

## Pick your setup

### 4K / 5K displays

Start with **`2025 Wallpaper`** and **`2026 Wallpaper`**, then **`MKBHDWallpapers`** and **`Apple Park`** (HEIC). You paid for pixels — use them.

### Ultrawide (21:9 / 32:9)

**`2025 Wallpaper`** and **`2026 Wallpaper`** — search `3440x1440`, `ultrawide`, automotive wides. Crop-friendly landscapes in Unsplash year folders.

### 1080p / older hardware

Everything scales down fine. Prioritize **`Texture`**, **`Stokes`**, **`2022–2023`** years for smaller file weights.

### iPad

**`2025 Wallpaper`** — YTECHB / iPad-optimized aspect ratios.

### iPhone

**`2021 Wallpaper`** → **iPhone 12 Wallpaper** (Live + static).

### Android

Any JPG/PNG; **16:9** and **18:9** assets abound.

### WallpaperEngine (dynamic)

Install via Steam. Some Workshop items need subscription. GPU recommended; disable aggressive battery saver for motion wallpapers.

## File formats & compatibility

| Format | Best for | Notes |
|--------|----------|-------|
| **JPEG** | Photos, large scenes | Smaller size, great for Unsplash/nature |
| **PNG** | Gradients, UI-clean art, lossless edges | macOS paired DM/LM sets |
| **HEIC** | Apple Park set | Native on macOS/iOS; Windows: HEIF extensions or convert |
| **WebP** | Modern web-sourced assets | Broad support on current OS versions |

**Windows HEIC tip:** Microsoft Store → *HEIF Image Extensions*, or batch-convert with ImageMagick / GIMP / CloudConvert.

## Curation philosophy

1. **Would I actually set this?** — keeper test  
2. **Does the folder teach a story?** — year or theme, never “misc_(final)(2)”  
3. **Resolution honesty** — keep native high-res; avoid upscaled mush  
4. **Annual closure** — each year gets its lane; active work lives in the current year folder  
5. **Special drops earn folders** — NASA Artemis II earned `Artemis II/`, not a buried filename
